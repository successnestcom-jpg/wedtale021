## Features

- **Interactive 3D Gatefold Card**: Realistic wax seal opening ceremony with fold animations.
- **Cultural & Regional Themes**: Traditional Tamil Hindu, Kerala Kasavu, Punjabi Royal, Rajput/Rajasthan Darbar, Muslim Nikah, and Christian Cathedral layouts.
- **Ceremony Timeline & Itinerary**: Interactive event schedules with locations, calendar integrations, and reminders.
- **Live Atmosphere FX**: Floating jasmine & rose petal showers, sparkles, and ambient sound effects.
- **Guest Personalization**: Dynamic RSVP, shareable customized links, and invitation QR code scanner.

## Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm (or bun / pnpm / yarn)

### Installation

```bash
# Install dependencies
npm install
# or clean install
npm ci
```

### Development

Run the local development server:

```bash
npm run dev
```

The application will be available at `http://localhost:3000`.

### Building for Production

Compile and bundle for production:

```bash
npm run build
```

The production assets will be generated in the `dist/` directory.

### Linting & Type Checking

```bash
npm run lint
```
